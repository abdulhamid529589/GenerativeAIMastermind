## The Three-Phase Production Workflow

### Traditional vs AI Filmmaking

**Traditional Film Production:**

```
Pre-Production → Production → Post-Production
     ↓               ↓              ↓
   Script        Shooting        Editing
   Budget      Equipment      Need more footage?
  Location        Cast        → Back to producer
   Crew         Filming      → Beg for money
                            → Film gets stuck
```

**AI Film Production:**

```
Pre-Production → Production → Post-Production
     ↓               ↓              ↓
   Script      Text→Image     Editing
  Planning    Image→Video    Need more?
   LLM        Select Model   → Generate again
  Prompts       Generate     → No extra cost!
```

**Major Shift:**
- **Cost:** Millions → Few dollars
- **Time:** Weeks → Hours
- **Flexibility:** Fixed → Infinitely iterative
- **Team:** 100+ people → 1 person

## Pre-Production: Blueprint Phase

### Step 1: Ideation with LLM

**Setup Your LLM (Claude Example):**

1. **Critical: Configure Settings**
   ```markdown
   Go to Settings → Add Custom Instructions
   
   Include:
   - Your company details
   - Your role
   - Your mission/narrative
   - Your style preferences
   - Target audience
   ```

2. **Why This Matters:**
   - LLM models its answers according to YOU
   - You don't need all information from the LLM
   - Only relevant information to your context
   - Saves time, improves quality

**Initial Concept Prompt:**

```
Hey Claude, I want to come up with a 30-60 second Red Bull ad.

I need to NOT make it a generic Red Bull ad. You understand what 
my narrative is? Give me five concepts which I can choose from.

Requirements:
- Nice storytelling
- Great visuals
- Everything made in AI
- One-line concepts only (for quick approval)
```

**Example Output (Red Bull Concepts):**

1. **The Forgotten Summit** - Himalayan porter discovers ancient manuscript at 8,000m revealing sherpas were original extreme athletes. Red Bull fuels race against avalanche to preserve truth.

2. **333 Velocity** - Mumbai Dabbawala breaks sound barrier on bicycle

3. **The Chandrayaan Mechanic** - Rural Indian teenager builds working rocket engine from scrap metal in 48 sleepless hours, proving ISRO's Mars mission wasn't fluke but civilizational DNA.

4. **Kalari Payattu Genesis** - Underground fighter discovers Red Bull awakens 3,000-year muscle memory from ancient warriors who moved faster than sight.

5. **The Monsoon Equation** - Kerala mathematician has 24 hours to solve climate equation, Red Bull keeps her conscious as she realizes solution was documented in ancient texts.

### Step 2: Human-at-the-Center Selection

**Critical Principle:**
> "Do NOT outsource your memory to AI. Use your instinct and taste."

**The Process:**
1. LLM generates options
2. YOU select based on gut
3. Don't overthink
4. Trust your taste
5. Move forward

**Selected Approach:**
- Combined all 5 concepts into montage
- Binding voiceover across scenes
- Theme: "Red Bull doesn't give you wings, it wakes the ones you forgot you had"

### Step 3: MVP (Minimum Viable Product)

**Before Full Production:**
- Test the concept quickly
- Use text-to-video directly
- Get visual feel
- Validate before investing time

**Platforms for MVP:**
- **Sora 2** (via Craya.ai)
- **Veo 3.1** (via Google Labs Flow)

**MVP Prompt Example:**

```
Rapid-fire montage of five scenes in quick succession:

1. Himalayan porter climbing through blinding snow (2-3 sec)
2. Mumbai cyclist navigating traffic at impossible speed (2-3 sec)
3. Rural workshop with teenager building rocket parts (2-3 sec)
```

**Assign AI a Specific Role:**

```
Think like:
- World-renowned ad director
- Brand strategist
- Expert in Red Bull ads

Task: Combine the five concepts, give me ONE singular concept.

Output needed:
- 30-second voiceover script
- Line-by-line visuals description
```

**Final Script (Example):**

```
VOICEOVER:
```

### Step 5: Scene-by-Scene Prompt Generation

**Prompt to LLM:**

```
Taking into consideration the script, build prompts for each

Cover entire script till title card.

Use all technical details from my master prompt (see below).
```

**Output:**
- One detailed prompt per scene
- Ready for image generation
- Maintains visual consistency
- Technical specifications included

## Production Phase 1: Image Generation

### The Master Prompt Formula

**Critical Framework:**

```markdown
┌──────────────────────────────────────────────────────┐
│              MASTER PROMPT STRUCTURE                 │
├──────────────────────────────────────────────────────┤
│  1. EMOTIONAL TONE                                   │
│     What feeling do you want?                        │
│     Example: Inspiring, energetic, powerful          │
│                                                      │
│  2. VISUAL REFERENCES                                │
│     Similar to what existing work?                   │
│     Example: Red Bull ads, Dark Knight, Dune        │
│                                                      │
│  3. SUBJECT                                          │
│     What/who is in the frame?                        │
│     Example: Sherpa on mountain with Red Bull       │
│                                                      │
│  4. COMPOSITION                                      │
│     How is the frame arranged?                       │
│     Example: Rule of thirds, centered, dynamic      │
│                                                      │
│  5. LIGHTING                                         │
│     What's the light quality?                        │
│     Example: Early morning Himalayas, sunlight,     │
│              snowstorm                               │
│                                                      │
│  6. CAMERA SETTINGS                                  │
│     Technical specifications                         │
│     Example: IMAX camera, anamorphic lenses         │
└──────────────────────────────────────────────────────┘
```

**Example Master Prompt:**

```
EMOTIONAL TONE: Inspiring, energetic, powerful, motivating, thrilling

VISUAL REFERENCE: Red Bull advertisements

SUBJECT: A weathered Himalayan sherpa in traditional camping gear, 
blue expedition jacket, prayer flags, helping a mountaineer. 
Red Bull can in hand, metallic surface catching light.

COMPOSITION: Dynamic, sherpa in foreground, mountains in background

LIGHTING: Early morning Himalayas, golden hour sunlight breaking 
through snowstorm, dramatic contrast

CAMERA: IMAX 70mm with anamorphic lenses, cinematic depth of field
```

### LLM Processing of Master Prompt

**Give to Claude:**

```
Below is the prompt which should act as your visual master prompt.

Build this prompt and make it more specific. Give me ONE single 
prompt so I can lock the visual theme.

[Paste your master prompt components]
```

**Claude Output:**
- Structured, detailed prompt
- Removes redundancy
- Adds necessary details
- Optimized for image models

**If Prompt Too Long:**

```
This prompt is too huge. Reduce it.

Keep all details I gave you.
Do not remove any actions.
Make it concise.
```

## Production Phase 2: Video Generation

### Text-to-Video vs Image-to-Video

**Text-to-Video:**
- ❌ Less control
- ❌ Unpredictable results
- ❌ Can't lock visual style
- ✅ Faster for MVP
- ✅ Good for testing

**Image-to-Video (Recommended):**
- ✅ Complete control
- ✅ Visual consistency
- ✅ Lock style first
- ✅ Professional results
- ❌ Two-step process

**Why Image-to-Video is Better:**
> "We maintain visual consistency by locking the image model first. This defines how entire video will look."

### Video Model Selection

**Available Models:**

| Model | Best For | Speed | Cost | Notes |
|-------|----------|-------|------|-------|
| **Kling** | Character animation | Slow | High | Best for people moving |
| **Halo 2.3** | Physics, fast motion | Fast | Medium | Great realism |
| **Qwen 2.5** | Sound effects | Medium | Medium | Auto-generates audio |
| **Sea Dance** | Camera movements | Very Fast | Low | Dolly shots, cuts |
| **Sora 2** | General purpose | Slow | High | Good quality |
| **Veo 3.1** | Quick generations | Fast | Low | Fast iterations |
| **Minimax** | Experimental | Medium | Medium | Chinese model |

### Model-Specific Prompting

**For Character Animation (Kling):**

```
Camera goes left to right cinematically and pulls back.
The guy starts walking ahead.

Duration: 5 seconds
```

**Why It Works:**
- Kling specializes in character movement
- Understands body mechanics
- Natural motion
- Facial expressions

**For Product Shots (Qwen 2.5):**

```
Camera crane goes from top and moves towards the guy, 
focusing on the Red Bull can.

Duration: 4 seconds
```

**Bonus:** Auto-generates sound effects!

**For Dynamic Action (Halo 2.3):**

```
Cinematically, the lady does Kalari Payattu.
Camera moves around in first-person POV.
Fast, dynamic shot.

Duration: 5 seconds
```

**Why It Works:**
- Halo 2.3 excels at physics
- Fast motion looks realistic
- Camera can move freely

**For Cuts and Camera Moves (Sea Dance):**

```
Camera pulls back from the guy and CUTS to 
close-up of Red Bull can.

Duration: 4 seconds
```

**Key Word:** "CUTS" - model understands editing

**For Dolly Shots (Sea Dance):**

```
Cinematic dolly shot. As lady is busy working, 
camera focuses on the Red Bull can.

Duration: 3 seconds
```

**For 360 Spins (Halo 2.3):**

```
Camera goes super fast, moves around in 360, 
and focuses on can in the center.

Duration: 4 seconds
```

**For Drone FPV (Various Models):**

```
Cinematic FPV shot of camera moving really fast 
through the mountaineers tracking towards sunlight.

Duration: 6 seconds
```

### The Generation Process

**In Craya.ai:**

1. **Select Image** from storyboard

2. **Click** "Turn into Video"

3. **Choose Model** based on shot type

4. **Enter Prompt** (camera movement, action)

5. **Set Duration** (3-12 seconds)

6. **Generate**

**Pro Workflow:**
```
Generate multiple shots simultaneously
- Shot 1 with Kling
- Shot 2 with Halo
- Shot 3 with Sea Dance
- Shot 4 with Qwen 2.5

Review all, pick best, continue
```

### Advanced Techniques

**Establishing Shots:**

```
Prompt to LLM:
"I want a prompt to establish a top helicopter view 
of Himalayan trackers moving through cold icy pathways. 
Make it super cinematic and match my lighting."

LLM generates optimized prompt
→ Create image with selected model
→ Convert to video with FPV motion
```

**Close-Up Product Shots:**

```
Prompt: "Camera travels very close to the giant Red Bull can, 
into one of the dew drops on the surface."

Model: Sora 2 or Kling
Result: Macro shot, water droplets, product focus
```

**Montage Sequences:**

```
Generate 5-7 quick shots (2-3 seconds each)
Hard cuts between them
Fast-paced energy
Red Bull aesthetic
```

### Troubleshooting

**If Video Doesn't Meet Expectations:**

1. **Regenerate** with same prompt
   - Results vary each time
   - May get better version

2. **Adjust Prompt**
   - More specific camera movement
   - Add emotional direction
   - Specify speed/energy

3. **Try Different Model**
   - Each model has strengths
   - Test alternatives

4. **Refine Source Image**
   - Better image = better video
   - Edit image first, then animate

**Common Issues:**

| Problem | Solution |
|---------|----------|
| Warping/distortion | Use Kling or Halo 2.3 |
| Slow motion | Specify "fast" or "dynamic" |
| Static shot | Add camera movement to prompt |
| Wrong focus | Specify "focus on [object]" |
| Poor physics | Use Halo 2.3 |
| No sound effects | Use Qwen 2.5 |

### The Editing Process

**Basic Workflow:**

1. **Import All Assets**
   ```
   - All video clips
   - Voiceover file
   - Music file
   - Sound effects (if separate)
   ```

2. **Create Project**
   - Set to 16:9 or 9:16 (vertical)
   - 1080p or 4K resolution
   - 24fps or 30fps

3. **Rough Assembly**
   - Lay out clips in order
   - Match to script/storyboard
   - Don't worry about timing yet

4. **Sync to Voiceover**
   - Place voiceover on timeline
   - Align visuals to words
   - Cut on voice pauses

5. **Add Music**
   - Place music track
   - Adjust volume (lower than voice)
   - Fade in/out

6. **Fine-Tune Timing**
   - Cut to the beat
   - Match energy of music
   - Remove dead space

7. **Sound Effects** (if using Qwen 2.5)
   - Already embedded in videos
   - Balance with music/voice

8. **Color Matching**
   - Ensure visual consistency
   - Basic color correction
   - Match mood across shots

9. **Transitions**
   - Hard cuts (Red Bull style)
   - Minimal fancy transitions
   - Fast-paced energy

10. **Title Card**
    - Brand logo
    - Tagline
    - Call to action

11. **Export**
    - MP4 format
    - H.264 codec
    - High quality settings

**Editing Tips:**

**For Ads:**
- ✅ Fast cuts (2-3 seconds per shot)
- ✅ Energy builds throughout
- ✅ Music drives the pace
- ✅ End with impact

**For Teasers:**
- ✅ Start middle end BUT leave trail
- ✅ Questions unanswered
- ✅ Intrigue over completion
- ✅ Call to action

**Common Mistakes:**
- ❌ Too many fancy transitions
- ❌ Shots too long (boring)
- ❌ Music too loud (drowns voice)
- ❌ Inconsistent pacing
- ❌ Weak ending

## Key Takeaways

### The Four Fundamentals of Storytelling

```markdown
┌────────────────────────────────────────┐
│  1. WHY (Your Purpose)                 │
│     Clear mission/reason               │
│     Example: Learn tools, tell story   │
├────────────────────────────────────────┤
│  2. IDEA (Your Concept)                │
│     Central theme                      │
│     Example: Red Bull wakes memory    │
├────────────────────────────────────────┤
│  3. HOW (Your Method)                  │
│     Execution approach                 │
│     Example: 5-scene montage          │
├────────────────────────────────────────┤
│  4. CAN IT BE BETTER?                  │
│     Continuous improvement             │
│     Example: MVP → Iterate → Polish   │
└────────────────────────────────────────┘
```

**If these four are clear, your story will never fall flat.**

### The Master Prompt Formula (Memorize This)

```markdown
EMOTIONAL TONE → VISUAL REFERENCE → SUBJECT → 
COMPOSITION → LIGHTING → CAMERA SETTINGS

Example:
"Inspiring, powerful | Red Bull ads style | Sherpa on mountain 
with Red Bull | Dynamic composition | Golden hour Himalayas | 
IMAX anamorphic lenses"
```
